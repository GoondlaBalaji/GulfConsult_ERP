20. Training
Definition

Training is the process in which a Machine Learning model learns patterns, relationships, and rules from the training dataset so that it can make accurate predictions on unseen data.

In simple words,

Training is the learning phase of a Machine Learning model.

Description

When a Machine Learning model is created, it has no knowledge.

For example,

model = LinearRegression()

At this point, the model is like a new student who has not studied anything.

When we call

model.fit(X_train, y_train)

the training process begins.

During training, the model:

Reads the training data

Finds relationships between Features (X) and Target (y)

Makes predictions

Compares predictions with actual values

Calculates the error

Updates itself to reduce the error

Repeats this process until it learns the pattern

21. Prediction
Definition

Prediction is the process of using a trained Machine Learning model to estimate the output (Target) for new, unseen input data.

In simple words,

Prediction is the application phase of Machine Learning.

Description

After training, the model has already learned patterns.

Now we provide new input data, and the model predicts the output.

Unlike training, prediction does not change the model.

The model simply uses the knowledge it has already learned.

23. Generalization
Definition

Generalization is the ability of a Machine Learning model to make accurate predictions on new, unseen data, not just the data it was trained on.

In simple words,

A good model should perform well on data it has never seen before.

Description

The ultimate goal of Machine Learning is not to memorize the training data.

Instead, the model should learn the underlying patterns so that it can make correct predictions for new data.

This ability is called Generalization.

Example

Suppose a model is trained using

800 House Records

Later,

100 completely new houses are given.

If the model predicts their prices accurately,

it has good generalization.

Good Generalization
Training Accuracy

95%

↓

Testing Accuracy

93%

Training and testing performance are very close.

This indicates that the model has learned the actual pattern.

Poor Generalization
Training Accuracy

99%

↓

Testing Accuracy

65%

The model performs well only on the training data.

It struggles with new data.

Why Is Generalization Important?

Imagine a student.

Student A

Memorizes previous question papers.

↓

Scores well only on repeated questions.

Student B

Understands concepts.

↓

Can solve new questions.

Student B has better generalization.

Machine Learning models should behave like Student B.

Factors Affecting Generalization

Good Training Data

↓

Good Features

↓

Proper Validation

↓

Enough Samples

↓

Correct Algorithm

↓

Good Generalization

Poor data or excessive model complexity can reduce generalization.

Real-Life Usage
Disease Prediction

Hospital trains on

100,000 patients.

Later,

New patient arrives.

The model correctly predicts the disease.

This demonstrates good generalization.

Spam Detection

The model has never seen today's email before.

Still,

It correctly predicts

Spam

This is another example of generalization.

Code
train_score = model.score(X_train, y_train)

test_score = model.score(X_test, y_test)

print(train_score)
print(test_score)

If both scores are similar,

the model generally has good generalization.

Key Points

Generalization is the main objective of Machine Learning.

Good models perform well on unseen data.

Memorizing the training data is not the goal.

Similar training and testing performance usually indicates good generalization.

24. Overfitting (Preview)
Definition

Overfitting occurs when a Machine Learning model learns the training data too well, including its noise and random patterns, causing poor performance on new, unseen data.

In simple words,

The model memorizes instead of learning.

Description

Imagine a student preparing for an exam.

Student A

Understands concepts.

↓

Can solve any question.

Student B

Memorizes every answer from previous exams.

↓

Fails when the questions change.

Student B represents Overfitting.

Example

Suppose we train a model using

1000 House Records

Training Accuracy

99%

Testing Accuracy

68%

This indicates that the model has memorized the training data but cannot predict well on unseen data.

Why Does Overfitting Happen?

Some common reasons are:

Very small training dataset

Model is too complex

Too many unnecessary features

Training for too long

Presence of noise in the data

Signs of Overfitting

Very high training accuracy

Low testing accuracy

Large gap between training and testing performance

Poor generalization

Simple Prevention Techniques

Collect more data

Remove irrelevant features

Use Cross Validation

Use Regularization

Choose a simpler model

Tune hyperparameters

We'll study these techniques in detail later in the roadmap.

Real-Life Example
Face Recognition

A model memorizes the faces of employees already in the database.

When a new employee joins,

the model fails to recognize them.

This is overfitting.

Medical Diagnosis

The model performs perfectly on historical patient records.

However,

it performs poorly on new patients.

Again,

this indicates overfitting.

Code

There is no single line of code that creates overfitting.

Instead, it is detected by comparing training and testing performance.

train_score = model.score(X_train, y_train)

test_score = model.score(X_test, y_test)

print("Training Accuracy:", train_score)

print("Testing Accuracy:", test_score)

Example Output

Training Accuracy = 99%

Testing Accuracy = 70%

This large difference is a warning sign of overfitting.

Overfitting vs Good Generalization
Good Generalization	Overfitting
Learns patterns	Memorizes data
Performs well on unseen data	Performs poorly on unseen data
Similar training and testing accuracy	Large gap between training and testing accuracy
Desired behavior	Undesired behavior
Key Points

Overfitting means memorizing the training data instead of learning patterns.

It results in poor performance on new data.

It is one of the most common problems in Machine Learning.

Cross Validation, Regularization, and more data are common ways to reduce overfitting.

Overfitting will be studied in much greater detail later under Core Machine Learning Concepts.

24. Overfitting (Preview)
Definition

Overfitting occurs when a Machine Learning model learns the training data too well, including its noise and random patterns, causing poor performance on new, unseen data.

In simple words,

The model memorizes instead of learning.

Description

Imagine a student preparing for an exam.

Student A

Understands concepts.

↓

Can solve any question.

Student B

Memorizes every answer from previous exams.

↓

Fails when the questions change.

Student B represents Overfitting.
